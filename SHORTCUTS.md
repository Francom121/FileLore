# FileLore — Keyboard Shortcuts & Mouse Interactions

The two **global** hotkeys are user-customizable in FileLore → Settings. The
combos below are the defaults; the in-app cheat sheet (menu bar icon →
*Keyboard Shortcuts…*, or FileLore menu → Help → *Keyboard Shortcuts…*)
always shows the **currently configured** keys.

## Global (work from anywhere, even when FileLore is in the background)

| Shortcut | Action |
| --- | --- |
| ⌥T *(default, customizable)* | Open the note editor for the current Finder selection |
| ⇧⌘F *(default, customizable)* | Open the Spotlight-style search over all noted files |

## FileLore active

| Shortcut | Action |
| --- | --- |
| ⌘F | Open the search window |

## Note Editor

| Input | Action |
| --- | --- |
| ⌘S | Save the note |
| ↩ / ⇥ / , (in the tag field) | Commit the tag being typed into a pill (comma splits pasted “a, b, c” into several pills) |
| ⎋ (in the tag field) | Clear the tag draft / cancel an inline tag edit |
| Double-click a tag pill | Edit the tag inline (↩/⇥ commits, ⎋ cancels) |
| Right-click a tag pill | Pin Tag / Unpin Tag |
| Click a linked-file row (or its Open button) | Open the linked file |
| Drag files onto the “Linked Files” dashed box | Link files to the note |

## Search Window

| Input | Action |
| --- | --- |
| ↩ (Return) | Open the selected result’s note |
| ⌘↩ | Reveal the selected result in Finder |
| ↑ / ↓ | Move the selection |
| Double-click a result | Open its note |
| Right-click a result | Open Note · Reveal in Finder · Export Note(s)… |
| ⌘-click / ⇧-click results | Multi-select (for batch Markdown export) |
| Click a tag filter chip | Toggle that tag as an AND-filter |
| Hover a tag filter chip → pin button | Pin / unpin the tag |
| Right-click a tag chip or result-row tag | Pin Tag / Unpin Tag |
| Click a pinned-tag chip | Filter to exactly that tag (click again to clear) |

## Menu Bar (FileLore status item)

| Input | Action |
| --- | --- |
| Click a recent file or pinned-tag file | Open its note |
| ⌥-click a recent file or pinned-tag file | Reveal it in Finder |

## Finder

| Input | Action |
| --- | --- |
| Right-click a file → Add/Edit FileLore Note | Open its note in FileLore |
| Right-click a multi-selection → Batch Tag with FileLore… | Open the batch tag/note editor |
| Right-click → Services → Open FileLore Note | Open its note (assign any shortcut in System Settings → Keyboard → Keyboard Shortcuts → Services) |
| Space (Quick Look) on a file with a note | Preview: media/text on the left, the FileLore note on the right |
| Drag file(s) onto the FileLore Dock icon | Open the note editor (multiple files → batch editor) |
| Drop file(s) onto the FileLore main window | Open the note editor (multiple files → batch editor) |

## Settings

| Input | Action |
| --- | --- |
| Click a shortcut recorder field, then press a combo | Rebind that global hotkey |
| ⎋ while recording | Cancel without changing the shortcut |
